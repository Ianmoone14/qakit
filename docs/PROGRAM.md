# QAKit — plan and weekly log

Edit this file yourself. Each week: fill **Hours**, **Meetings** (optional), **Notes**.

Official cap: **8 hours** per delivery week. Meetings are optional — add a row only when one happens.

Weeks run **Monday–Sunday**. Today’s anchor: Thursday 27 Aug 2026 (W1).

## How to log

Copy this under the week:

```
- Hours:
- Meetings: (optional — date, who, duration, outcome)
- Notes:
```

If there was no meeting, write `Meetings: none` or leave it empty.
